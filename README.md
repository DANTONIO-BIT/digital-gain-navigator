# DigiDot Web

Consultoría digital para autónomos, PYMEs y restaurantes en Sevilla — diagnóstico digital gratuito, webs a medida, CRM, automatización de procesos y marketing local.

## Stack

Vite + React + TypeScript + Tailwind + shadcn/ui, GSAP para animaciones, Recharts para gráficos. Sin backend todavía (ver pendientes de captación de leads).

## Desarrollo

```
npm install
npm run dev
```
